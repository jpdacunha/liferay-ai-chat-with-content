Docker Compose Web Consoles

Quick access to services exposed in runtime/docker-compose.yml.

Liferay

Web port: 8080

http://localhost:8080

Kibana

Web port: 5601

http://localhost:5601

Elasticsearch

API HTTP: 9200

http://localhost:9200

MySQL (database)

No web console is exposed in this compose file. SQL access is available via a client on localhost:3306.

Ports can be customized using compose environment variables (LIFERAY_HOST_PORT, KIBANA_HOST_PORT, ELASTICSEARCH_HOST_PORT, MYSQL_HOST_PORT).
